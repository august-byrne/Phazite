# Open questions

This page lists what waits for the owner's answer: the design questions that are still open, and every choice that was
made on the owner's behalf and marked for the owner to review. To use it, write an answer in the last column of each
row ("keep" is an answer); a row that is answered leaves this page, and one that changes Phazite goes into
[design/decisions.md](design/decisions.md) and the area's page.

Within each area, the rows that would change the most work if answered differently come first. "Built" means the
choice is in the code as described; what is not built says so.
